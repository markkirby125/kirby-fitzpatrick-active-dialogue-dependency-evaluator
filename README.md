## Core Patterns

- **Dependency Evaluator**: Dialogic Dependency Evaluation: rigorously contrast concrete bottleneck solved vs security/maintenance surface added.
- **Practical Application**: Auditing new `npm`, `cargo`, and `pip` dependencies to prevent bloat.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
